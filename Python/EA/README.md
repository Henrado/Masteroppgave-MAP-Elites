# Forskjellige individer og deres kontrollere 
## Controllers inneholder de fem kontrollerene:
Dessverre har disse forskjellige navn fra hva som er i filen og hva som står beskrevet i oppgaven:
Sinecontroller=SineFreq
SinecontrollerUfq=Sine
TanhController=Tanh
TanhControllerWoff=TanOff
TanhControllerWOffFq=TanOffFreq


## Individuals inneholder de tre kontrollteknikkene: 
Disse har også forskjellige navn i forhold til hva som står i oppgaven: 
Individual_zeroLocked = Ikke delt
Individual_twoLock = Segment delt 
Individual_globalLock = Fult delt
